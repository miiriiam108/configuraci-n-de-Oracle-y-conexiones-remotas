# configuraci-n-de-Oracle-y-conexiones-remotas

## Bloque 1. Entorno
1. Abrir las variables de entorno
   1. Pulso a la vez la tecla windows + r.
   2. Escribo: sysdm.cpl y entro.
   3. Vamos a opciones avanzadas y pulsamos en variables de entorno.
  
2. Buscar las variables.
   1. Buscamos si existen:

      - ORACLE_HOME -> contiene dónde está instalado Oracle.
      - ORACLE_BASE -> contiene la carpeta raíz de Oracle.
      - RACLE_SID -> contiene el identificador de la instancia
